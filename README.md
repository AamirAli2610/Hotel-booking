# 🏨 Hotel Booking Website

A responsive **Hotel Booking Website** built with **React.js**. Users can browse hotels, view hotel details, and navigate to a booking page.

## 🚀 Features

* Browse hotels
* View hotel details
* Hotel booking page
* Dynamic routing with React Router
* Booking & cancellation functionality
* Conditional rendering
* Reusable React components
* Responsive UI
* CSS Modules
* Font Awesome icons

## 🛠️ Tech Stack

* React.js
* JavaScript
* React Router
* CSS Modules
* Font Awesome
